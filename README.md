# local-auth

Static OAuth callback pages for local command-line tools, published with GitHub Pages.
They only show the answer of the provider as one line `<code> <state>` to paste into the
terminal. They store and send nothing.

| Provider | Redirect URI |
|----------|--------------|
| Google   | `https://gainto.github.io/local-auth/google/callback/` |
| TikTok   | `https://gainto.github.io/local-auth/tiktok/callback/` |

`tiktok/` also holds the pages (`index`, `privacy`, `terms`) the TikTok app registration asks for.
